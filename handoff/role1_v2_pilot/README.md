# V2 证据动作与漏答评分小试验（训练侧，2026-11-27）

## 已实现的隔离接口

`core/v2_evidence.py` 新增独立 `EvidenceRunner`，其动作顺序为 `retrieve_more`、`rewrite_query`、`open_section`、`write`，`observe()` 给出动作掩码、当前查询、缺口、已检索论文、已打开章节和 Token 成本。`rewrite_query` 只看公开题面与当前标题、摘要，生成具体缺口和英语检索词；下一次检索才使用新词。`open_section` 只能打开**已检索**论文在 `data/v2_pilot_sections.json` 中登记的段落，返回论文 ID、章节 ID、来源位置与 SHA-256；正文在打开前不会进入写作请求。模型和 Judge 的原始请求/响应均保存在本次轨迹中，不含凭证。

这是一份手工核过来源的**单篇正文训练试验**，不是三号位的正式全文发布。V1 的五动作、冻结摘要语料、Judge 和二号位现有 DQN 接口均未改动；这四个 V2 动作还不能直接送进固定五动作的 DQN。代码只接受 `split=train`，不读测试题或评分标签。论文正文来源：[arXiv:2008.02646v1](https://arxiv.org/pdf/2008.02646v1)，讨论章节 PDF 第 7 页。

## 真实动作链与消融

用 R022 训练题加一个公开的触觉键盘聚焦要求，首次只取 1 篇论文。各路线只运行一次，均使用官方 `deepseek-flash`；Token 为各模型调用报告的工作流 Token，检索/本地打开动作本身无模型 Token。原始轨迹为同目录 `runner_*.json`。

| 路线 | 动作 | Token | 获得触觉键盘论文 | 打开讨论段落 | 终稿包含 HER 与最高约 10 倍 |
| --- | --- | ---: | --- | --- | --- |
| `baseline` | 检索→写 | 1,004 | 否 | 否 | 否，明确说材料不足 |
| `no_fulltext` | 检索→改词→检索→写 | 1,656 | 是 | 否 | 否，明确说摘要未说明 |
| `no_rewrite` | 检索→检索→打开→写 | 1,671 | 是 | 是 | 是 |
| `adaptive` | 检索→改词→检索→打开→写 | 2,197 | 是 | 是 | 是 |

`adaptive` 的改词理由是当前仅有迁移预测论文，缺少触觉键盘的实机证据；改词后的首次结果是 `2008.02646v1`。然而原查询再次检索也会拿到这篇论文，且 `no_rewrite` 更省 Token。因此**此题证明打开正文带来了摘要没有的答案信息，没有证明改词优于继续用原查询**。四条路线同时改变了证据量与模型调用次数，不能把最终质量差额归因于单个动作或作为 DQN 训练成绩。

另用原始 R022 题面（不加触觉聚焦要求）做了一次改词检索探针，见 `rewrite_original_r022.json`。原查询的第二批会检出训练侧证据清单中的 `1807.11174v1`、`2008.02646v1`；该次改词后的第二批没有检出这两篇。改词是一个有可能损失证据的选择，不能设为固定步骤。证据清单只用于**离线诊断**，不进入 Runner。

## 漏答评分门槛

`evaluation/v2_sensitivity.py` 是独立于 V1 冻结 Judge 的**临时训练试验评分器**。题目明确列出六个要点。Judge 对每个“已覆盖”要点必须复制候选答案中的连续原文；本地校验拒收虚构的答案片段，并对方法、幅度和适用任务检查关键关系。程序根据六项布尔结果计算 coverage，再与事实、引用、一致性分数求平均。

最初的自然语言评分曾把一份漏掉 HER、10 倍和适用任务的答案判为满分，理由还写出答案中不存在的事实，因此**该回执无效**。加上答案片段绑定后，独立盲评同一问题的纯漏答稿与完整稿：coverage 分别为 **0.50（3/6）** 和 **1.00（6/6）**，事实、引用、一致性均为 1.00，overall 分别为 0.88 和 1.00。精确请求、响应和按当前校验规则重算的分数见 `judge_calibration.json`。这只通过**一个受控漏答对**；还需更多题目、错引和事实错误反例及人工复核，才能冻结为正式奖励。

## 给后续集成的界线

- 一号位：正文发布要从手工单段扩展到多论文、多章节，并保留来源位置和摘要绑定；改词策略需比较原查询继续检索与改词检索的证据收益。
- 二号位：当前 `rl/` 编码器和网络输出宽度固定为 V1 五动作。V2 正式训练前应另做版本化状态编码、动作顺序与掩码，并纳入文本证据成本；不可把本试验轨迹混进 V1 回放池。
- 三号位与评分方：冻结 V2 任务、正文段落和题点；在多组人工核对的漏答、错引、捏造、混淆场景上验证 Judge，再交付独立测试。V1 的摘要分数不可直接比较 V2 的全文分数。

本目录记录了真实信息增益与失败案例，**尚不能证明 V2 DQN 可训或优于规则策略**。
